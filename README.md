# التاجر الذكي — Smart Trader

تطبيق ويب تقدمي محلي لإدارة الجهات والأصناف والمواصفات والأسعار اليدوية، وحساب تكلفة الشحنة والتسعير، وإعداد تقارير القرار وقوائم التصدير. يعمل التطبيق محلياً في المتصفح ويخزّن بيانات العمل في **IndexedDB** على جهاز المستخدم، من دون حسابات أو خادم بيانات أو تحليلات خارجية.

## الوظائف الرئيسية

يساعد التطبيق التاجر على تسجيل الجهات التجارية والأصناف والمواصفات الفنية والأسعار المؤرخة، ثم إنشاء ملف تكلفة شحنة متعدد الأصناف يوزع المصروفات والجمارك ويقترح سعر البيع. كما يوفر تقارير مقارنة المسارات وتفكيك تكلفة الشحنة، والتصدير إلى Excel وPDF، وإدارة المرفقات والمهام، ونسخاً احتياطية محلية قابلة للاستعادة أو الدمج.

## المتطلبات

يتطلب المشروع Node.js حديثاً و**pnpm 10.4.1**. لا يحتاج إلى قاعدة بيانات أو حسابات سحابية أو مفاتيح API أو ملف `.env` للتشغيل المحلي.

| الأداة | الأمر |
| --- | --- |
| تثبيت الاعتمادات المقفلة | `pnpm install --frozen-lockfile` |
| تشغيل التطوير | `pnpm dev` |
| اختبار الوحدات | `pnpm test` |
| فحص TypeScript | `pnpm run check` |
| بناء الإنتاج | `pnpm run build` |
| تشغيل خادم الإنتاج | `pnpm start` |
| تدقيق جميع التبعيات | `pnpm audit` |
| تدقيق تبعيات الإنتاج فقط | `pnpm audit --prod` |

بعد تنفيذ `pnpm start`، يفتح التطبيق افتراضياً على `http://localhost:3000`. يمكن تغيير المنفذ اختيارياً عند التشغيل، مثل `PORT=3010 pnpm start`.

## النسخ الاحتياطي واستعادة البيانات

البيانات محفوظة داخل المتصفح؛ لذلك ينبغي إنشاء نسخة احتياطية بانتظام من صفحة **النسخ الاحتياطي**. يُنشئ التطبيق ملف JSON داخلياً يحتوي سجلات العمل والمرفقات والمهام والإعدادات المرتبطة بالبيانات. لا تشارك ملف النسخة الاحتياطية مع العملاء لأنه قد يتضمن تكاليف وملاحظات خاصة.

عند الاستعادة، اعرض معاينة محتوى الملف أولاً ثم اختر بين الاستبدال الكامل أو الدمج الآمن. رمز الدخول المحلي لا يدخل في النسخة الاحتياطية عمداً، لحماية الوصول إلى الجهاز.
